# CrushChatter

A friendly, character-first AI chat app. Pick a character on **Discover**, connect an AI, and start chatting.

- Browse and search characters as cards, with tags and favorites
- Import bots by link (Chub, JannyAI, Pygmalion, RisuAI and more): see `tools/import-bots.js`
- Runs locally. Your chats and characters stay on your computer
- Optional standalone Windows app: see `desktop/README.md`

## Quick start

1. Install [Node.js](https://nodejs.org).
2. Double-click `Start.bat` (Windows) or run `node server.js`.
3. Open the address it prints, then click **Connect AI**.
